# Video uploads

Drop each project's videos into its own folder here:

- `01-refraction-effect/`
- `02-spotify-onboarding/`
- `03-framer-shaders/`
- `04-typography-animation/`
- `05-hire-me-button/`
- `06-motion-text-animation/`

**Naming**
- `cover.mp4` is the main video. It plays muted on a loop on the project card and at the top of the project page.
- `01.mp4`, `02.mp4`, … are any extra clips shown below it, in order.

**Tips**
- `.mp4` (H.264) or `.webm`. Sound isn't needed, the videos play muted.
- Keep each file under about 50MB. GitHub rejects anything over 100MB.
- Then tell Claude "videos are uploaded". Claude moves them into the site, wires them up and checks the build.
