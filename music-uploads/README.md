# Music uploads

Drop 2-3 `.mp3` files here, then tell Claude "music is uploaded". Claude moves them into the site and lists them in the player on the Experiments page.

- Only use music you have the rights to: your own, royalty-free, or Creative Commons (with credit).
- Keep each file under about 10MB.
- Tell Claude the title and artist for each track so they show in the player.
